무작위 짝 배정 서비스

간편하게 무작위로 짝을 배정해 줍니다.

서비스 소개

참여자를 자동으로 무작위 짝으로 배정하는 서비스

주요 기능

• 무작위 짝 배정

참여한 사람들을 자동으로 섞어 짝을 배정합니다.

• 간편한 입력

이름을 입력하면 별도의 복잡한 설정 없이 바로 배정할 수 있습니다.

• 빠른 결과 확인

배정 버튼을 누르면 바로 결과를 확인할 수 있고 새로운 짝을 다시 배정할 수도 있습니다.

이용 방법

  1. 서비스에 접속합니다.
  2. 참여할 사람의 이름을 입력합니다.
  3. 짝 배정 버튼을 클릭합니다.
  4. 시스템이 참여자를 무작위로 짝지어 줍니다.
  5. 배정된 짝을 확인합니다.
